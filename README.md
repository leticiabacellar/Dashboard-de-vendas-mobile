# 📊 Dashboard de Análise de Vendas

![Dashboard](images/dashboard.png)

## 📌 Sobre o Projeto

Este projeto apresenta um dashboard desenvolvido no **Power BI** para análise de desempenho comercial. O painel reúne os principais indicadores de vendas, permitindo acompanhar o faturamento, volume de itens vendidos, quantidade de pedidos e desempenho por vendedor, cliente, produto e estado.

O dashboard foi desenvolvido com foco em fornecer uma visão estratégica das operações comerciais, auxiliando gestores na identificação de oportunidades de crescimento e na tomada de decisões baseada em dados.

---

## 🎯 Objetivo

Desenvolver um dashboard executivo para monitorar os principais indicadores de vendas, permitindo analisar o desempenho comercial sob diferentes perspectivas e apoiar decisões estratégicas.

---

## 📂 Etapas do Projeto

### 📥 Coleta dos Dados

- Importação da base de vendas.
- Organização das informações comerciais.
- Validação da consistência dos dados.

### 🔄 Tratamento dos Dados

Durante o processo de ETL foram realizadas atividades como:

- Remoção de registros duplicados;
- Tratamento de valores nulos;
- Padronização das informações;
- Ajuste dos tipos de dados;
- Criação de colunas auxiliares para análise.

### 🧩 Modelagem dos Dados

Foi desenvolvido um modelo relacional utilizando boas práticas de modelagem de dados, garantindo maior desempenho nas consultas e nas visualizações.

---

## 📐 Indicadores Desenvolvidos

O dashboard apresenta os seguintes KPIs:

- 💰 Receita Total
- 📦 Itens Vendidos
- 🛒 Quantidade de Pedidos
- 👤 Receita por Vendedor
- 🏢 Receita por Cliente
- 📍 Receita por Estado
- 📦 Análise de Produtos

---

## 📊 Funcionalidades do Dashboard

O painel permite analisar:

- Receita total da empresa;
- Quantidade total de pedidos;
- Total de itens vendidos;
- Ranking de vendedores por faturamento;
- Receita por cliente;
- Receita por estado;
- Comparação entre produtos considerando faturamento e volume de vendas;
- Filtros por estado para análise detalhada.

---

## 📈 Principais Insights

Com este dashboard é possível:

- Identificar os vendedores com melhor desempenho.
- Comparar o faturamento entre estados.
- Avaliar os clientes que mais geram receita.
- Identificar produtos com maior faturamento e volume de vendas.
- Monitorar indicadores estratégicos para apoiar decisões comerciais.
- Detectar oportunidades para aumento das vendas.
